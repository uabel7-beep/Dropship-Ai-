# DROPSHIP AI V5

V5 ajoute un moteur d'intelligence produit plus transparent :
- score commercial pondéré ;
- signal de potentiel/tendance ;
- raisons positives et avertissements ;
- sauvegarde étendue des produits live ;
- migration SQLite automatique.

Important : sans historique de plusieurs observations, le signal de tendance n'est pas une détection de tendance réelle. Il s'agit d'un signal de potentiel basé sur les données actuelles.
